# Goodreads Node Server

A Node.js/Express backend for a Goodreads-like application.

## Tech Stack

- Node.js / Express
- MongoDB / Mongoose
- Google Books API

## Project Structure

```
Goodreads/
├── Books/        # Book CRUD and search
├── BookShelf/    # User bookshelves
├── Reviews/      # Book reviews
├── Users/        # User authentication
├── Requests/     # Book requests
└── Search/       # Google Books API integration
```
